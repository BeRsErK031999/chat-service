Что нужно сделать:
1. Установить Time Tracker Desktop Setup 0.1.24.exe.
2. Войти в десктопное приложение.

4. Проверить: открытие чата, отправку сообщений, переключение комнат, unread/activity, ActivityPanel, клавиатуру, закрытие/повторное открытие и работу в течение дня.
