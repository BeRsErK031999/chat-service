# Chat Beta Launch Checklist

Use this checklist before sending the 0.1.24 installer to the first 2-5 testers.

## Build And Data

- [ ] Desktop installer is built: `Time Tracker Desktop Setup 0.1.24.exe`.
- [ ] Beta users are prepared.
- [ ] Beta rooms are created on the office backend database.
- [ ] Authenticated `/rooms` smoke confirms seeded rooms are visible.
- [ ] Rollback plan is known.

## Feedback Setup

- [ ] `Chat Beta Feedback` group is created.
- [ ] [Tester instructions](./chat-beta-tester-message.md) are sent.
- [ ] [Feedback template](./chat-beta-feedback-template.md) is available in the group.
- [ ] [Beta scope](./chat-beta-scope.md) is available to the launch owner.
- [ ] [Triage process](./chat-beta-triage.md) is available to the triage owner.

## Tester Start

- [ ] Testers received the installer path.
- [ ] Testers know to open chat with `Ctrl+Shift+Alt+C`.
- [ ] Testers know where to report issues.
- [ ] Testers know not to include passwords, tokens, or secrets in screenshots/logs.

Related plan: [Chat Beta Launch Plan](./chat-beta-launch-plan.md).
