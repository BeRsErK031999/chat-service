# Chat Beta Scope

## What We Test

- Opening chat from the desktop app.
- Sending messages.
- Switching rooms.
- Unread and activity behavior.
- ActivityPanel behavior.
- Keyboard navigation.
- Closing and reopening the overlay.
- Long-running desktop work with chat left open.

## What We Do Not Test

- `users-service`.
- Production rollout.
- External integrations.
- Future chat features.
- File upload, reactions, typing indicators, edit/delete, or other planned enhancements.

Use [Chat Beta Feedback Template](./chat-beta-feedback-template.md) for reports and [Chat Beta Triage](./chat-beta-triage.md)
for severity.
